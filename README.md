# ManualBuilder — منشئ الأدلة المؤسسية

برنامج Windows لإنشاء الأدلة المؤسسية (النظام الداخلي، السياسات والإجراءات، الحوكمة، الهيكل التنظيمي، الالتزام) بالعربية والإنجليزية، وتصديرها PDF للطباعة وWord ونسخة HTML تفاعلية، مع الاستيراد من Word وHTML وPDF.

- المثبّت: `ManualBuilderSetup.exe` من الإصدار `latest` (يُبنى آلياً في GitHub Actions).
- دليل الاستخدام: [`docs/ManualBuilder.md`](docs/ManualBuilder.md) — المتطلبات: [`docs/Requirements.md`](docs/Requirements.md).
- قواعد التطوير: [`CLAUDE.md`](CLAUDE.md).

الخطوط المضمّنة (Tajawal وCairo وNoto Naskh Arabic وAmiri) برخصة SIL OFL، وPaged.js برخصة MIT (`assets/web/LICENSE.md`).
